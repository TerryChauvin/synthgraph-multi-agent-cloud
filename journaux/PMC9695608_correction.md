- Constat 2 (calcite) : résultat `secondary_phase` ajouté sur les six branches x > 0,2 à 90 °C (Ca0.3, 0.4, 0.5, 0.6, 0.8 et CaFe2O4_90C), citation = phrase des DRX ; `value_text` recopie les mots de l'article (« calcite (calcium carbonate) rhombohedral structure belonging to the R3c space group »). - Constat 3, ILP (Fig. 7A, x = 0 et 1) : lecture après agrandissement, échelle 0 à 4 calée sur le point noir connu (3,7). x = 0 : 1,1 / 1,0 / 0,85 ; x = 1 : 0,35 / 0,18 / 0,43 (382,6 / 270,6 / 161,6 kHz). - Constat 7 (libellé « 90C » sans citrate) : libellé non renommé (la critique scientifique l'utilise) ; doute ajouté disant que la température et les quantités ne sont pas dites. Le doute existant sur l'héritage des étapes est conservé.
