- (a) x = 0 comme base avec le protocole générique : j'ai jugé l'héritage fondé et n'ai pas fait de constat. L'unique paragraphe Experimental décrit la formule générique Co0.7Zn0.3GdxFe2−xO4 ; x = 0.0 est un membre de la série, et omettre le nitrate de gadolinium est la lecture littérale de x = 0. Le doute et la limite_reproductibilite de l'extraction le signalent déjà ; je l'ai mis en notes.
- (b) Table 2 : rangée Fe octaédrique, x = 0.1 = 1.9895 (5). J'ai vérifié toutes les colonnes : la somme des occupations du site B (Co 0.7 + Gd + Fe) donne 1.9999, 1.9999, 1.9998, 1.9999 pour x = 0 à 0.075 et 2.79 pour x = 0.1 ; le site A (Zn 0.3 + Fe) donne bien 0.9988 à 0.9995. Seule la valeur de x = 0.1 est aberrante. Constat `manquant`, `sure` : la règle du projet est de recopier l'incohérence avec un doute, pas de l'écarter. Je ne propose pas 1.1995 comme valeur, seulement comme hypothèse de lecture dans la correction.
