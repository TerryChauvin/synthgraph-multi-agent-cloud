# Journal — classement des mécanismes, lot B (256 voies)

1. Auteurs sans mécanisme de formation (photocatalyse, capteur, propriété seule) : `type_auteurs = non_decrit` et `accord = nuance`, avec un motif qui commence par « formation non décrite » (39 voies). Une absence de mécanisme ne peut pas être un accord.
2. Gravure de type Hummers et chimie de greffage ou de couplage (EDC, SOCl2, silanes, diazotation) : classe `autre`, faute de classe « oxydation » ou « fonctionnalisation ».
3. Gravure des MXènes et découpe de g-C3N4 : `exfoliation_delamination` ; précipitation du zincate et transformations hydrothermales : `dissolution_recristallisation` ; coprécipitation d'hydroxydes et sol-gel d'alcoxydes : `hydrolyse_condensation`.
4. Polycondensation de g-C3N4 et points de carbone de type Maillard/amide (IPCA) : `polymerisation_reticulation` ; carbonisation et combustion (Pechini, glycine-nitrate) : `decomposition_thermique_pyrolyse`.
5. Synthèses vertes Ag/Au : `reduction_chimique`. Si le critique juge que l'AgCl domine le produit, `desaccord` avec `nucleation_croissance_classique` (précipitation). Si l'AgCl n'est qu'une phase secondaire possible, `nuance`.
6. `desaccord` réservé aux cas où le mécanisme dominant change (gabarit vs agrégation, combustion vs simple décomposition), ou quand l'étape clé des auteurs est jugée impossible (dismutation sans redox, coupure glycosidique en base, sulfonamide sans activation, Si(0) sans réducteur). Une simple réserve sur une preuve donne `nuance`.
7. `incompatibilite_conditions` mise à vrai pour 15 voies seulement, quand une condition listée contredit matériellement le mécanisme : chlorure de HAuCl4 avec Ag+, cible Au0 « réduite », TiO2 + N2 à 900 °C, absence de combustible, absence d'acide, calcination à 400 °C pour ZrSiO4, précurseurs insolubles, citrate ou catéchol pour Si(0), lavage éthanolique du chlorure d'acyle, dessalage sans NHS, PbSO4 précipité avant les nanocristaux, amines protonées dans HCl 2 M, NP de ZnO dissoutes par l'acide acétique.
8. Je n'ai pas compté les suspicions graves qui restent probables mais non prouvées (imidisation à température ambiante, Cd en surface, gel de méthylcellulose) : elles sont en `nuance` ou `desaccord` sans incompatibilité.
9. `fondateurs` : seulement les sources de references/fondateurs.md nommées ou dont la méthode est désignée (« type Turkevich », « type Stöber », « type Pechini », « méthode de Marcano », fluorophores moléculaires → Essner). `fondateur_manquant` : Iravani pour les extraits végétaux, Cundy & Cox pour les zéolithes, Essner pour les points de carbone, Hench & West pour le sol-gel, Baruah & Dutta pour ZnO en solution.
10. Le dossier est partagé avec un autre agent (dump.py modifié pendant mon passage) : j'ai travaillé avec des fichiers suffixés B (dumpB.py, jugB.txt, buildB.py, B_c.txt) et je n'ai rien modifié dans le dépôt.
